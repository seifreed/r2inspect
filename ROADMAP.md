# Roadmap

## 3.0.1 - Release hardening

- Required CI and publication gates.
- Reproducible signed container and pinned fixtures.
- Canonical license and maintained project documentation.
- Correct plugin categories and extraction error semantics.

## 3.1.0 - Stable report contract

- `r2inspect.report/v1` JSON Schema.
- Typed analyzer outcomes, findings, evidence, and provenance.
- Normalized PE, ELF, and Mach-O security properties.
- `fast`, `standard`, and `deep` analysis profiles.

## 3.2.0 - Analytical validation

- Public sanitized benchmark corpus and private nightly corpus.
- Precision, recall, error, timeout, latency, and memory metrics per analyzer.
- Reproducible benchmark reports attached to releases.

## 3.3.0 - Analyst workflows

- Optional capa and FLOSS analyzers.
- Explainable findings, offline HTML, SARIF, MISP/STIX, comparison, and baselines.

## 4.0.0 - Backend orchestration

- Format-specific backend adapters.
- Automatic backend selection and cross-backend consensus reporting.
